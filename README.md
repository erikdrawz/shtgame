# Is it a shit game?

Parody game-rating site. Type a game and get one of three verdicts: not shit (80+), shit (50–79), gigantic shit (49 and below). Players outrank critics.

Scores powered by [VideoGamesCritic](https://videogamescritic.com). Not affiliated.

Static prototype: `index.html` calls the VideoGamesCritic API straight from the browser. Freshly rated is stored per browser for now.
